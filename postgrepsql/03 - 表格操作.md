创建表格

``` postgresql
create table cars (
	brand varchar(255),
	model varchar(255),
	year int
);
```



查询数据库所有表格

``` postgresql
-- 一般使用元命令
postgres=# \d
        List of relations
 Schema | Name | Type  |  Owner
--------+------+-------+----------
 public | cars | table | postgres
(1 row)
-- 也可以用 sql 命令，较复杂
postgres=# select table_name from information_schema.tables where table_schema = 'public';
 table_name
------------
 cars
(1 row)
```
