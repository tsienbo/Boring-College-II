创建表格

``` postgresql
create table cars (
	brand varchar(255),
	model varchar(255),
	year int
);
```

语法糖 `serial`

``` postgresql
create table students (
	id serial primary key,
         name varchar(255)
);
-- 这里的 serial 是语法糖，做三件事：创建序列、字段 int、默认值 nextval (' 序列名 ')。不能通过 alter table students alter id type int primary key 修改类型
```





查询数据库所有表格

``` postgresql
-- 一般使用元命令
postgres=# \d
        List of relations
 Schema | Name | Type  |  Owner
--------+------+-------+----------
 public | cars | table | postgres
(1 row)
-- 也可以用 sql 命令，较复杂
postgres=# select table_name from information_schema.tables where table_schema = 'public';
 table_name
------------
 cars
(1 row)
```



查询表格详细信息

``` postgresql
postgres=# select * from cars;
 brand | model | year
-------+-------+------
(0 rows)
```
