``` postgresql
-- 返回当前连接的数据库名称
select curremt_database();
```

查看所有数据库

``` postgresql
select datname from pg_database;
-- 在客户端中，可使用 \l 查看
```

创建数据库

``` postgresql
create database dbname;
```

删除数据库

``` postgresql
drop database dbname;
-- 如果数据库不存在，会报错，可以加 if exists 发出提示而不是错误
drop database if exists dbname;

```

删除数据库还可以通过 shell ，注意指定用户名为 postgres ，否则使用计算机用户名（我的是 Qiavo）
``` bat
dropdb -U postgres dbname
```



在客户端中，通过 `\c + 数据库名` 切换数据库，在客户端外只能新建连接来切换数据库

``` postgresql
postgres=# \c test
You are now connected to database "test" as user "postgres".
test=# 
```
