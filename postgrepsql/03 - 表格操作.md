创建表格

``` postgresql
create table cars (
	brand varchar(255),
	model varchar(255),
	year int
);
```



查询数据库所有表格

``` postgresql
-- 一般使用元命令
postgres=# \d
        List of relations
 Schema | Name | Type  |  Owner
--------+------+-------+----------
 public | cars | table | postgres
(1 row)
-- 也可以用 sql 命令，较复杂
postgres=# select table_name from information_schema.tables where table_schema = 'public';
 table_name
------------
 cars
(1 row)
```



查询表格详细信息

``` postgresql
postgres=# select * from cars;
 brand | model | year
-------+-------+------
(0 rows)
```

查询表格表项信息

``` postgresql
postgres=# \d cars
                       Table "public.cars"
 Column |          Type          | Collation | Nullable | Default
--------+------------------------+-----------+----------+---------
 brand  | character varying(255) |           |          |
 model  | character varying(255) |           |          |
 year   | character varying(4)   |           |          |
 color  | character varying(255) |           |          |
 age    | integer                |           |          |
```

删除表格

``` postgresql
drop table cars;
```
