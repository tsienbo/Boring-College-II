插入数据

``` postgresql
postgres=# insert into cars (brand, model, year)
postgres-# values ('Ford', 'Mustang', 1964);
INSERT 0 1
```

插入多行数据

``` postgresql
postgres=# insert into cars (brand, model, year)
postgres-# values
postgres-# ('Volvo', 'p1800', 1968),
postgres-# ('BMW', 'M1', 1978),
postgres-# ('Toyota', 'Celica', 1975);
INSERT 0 3
```

删除数据

``` postgresql
delete from cars
where brand = 'Volvo';
```



查询指定表项

``` postgresql
select brand, year from cars;
```

增加表项

``` postgresql
alter table cars 
add color varchar(255);
-- 或加上 column 
alter table cars
add column color varchar(255);
```

更新表项

``` postgresql
alter table cars
alter column year type varchar(4);
-- 或简化 column
alter table cars
alter year type varchar(4);
```

丢弃表项

``` postgresql
alter table cars
drop column color;
-- 或简化 column
alter table cars
drop color;
```



更新表项数据

``` postgresql
update cars
set color = 'red'
where brand = 'volvo';
```
